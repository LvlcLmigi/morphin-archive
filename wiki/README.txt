How the wiki works

Each article is a Markdown file in this folder (any subfolder). The site build turns them into pages at
powerrangers.volbeat.vip/?t=wiki. Pages for every comic series, comic issue, character with a card and enemy deck
are made automatically as stubs; writing a file with the same title (or, for comics, the same comic:/series: id)
replaces the stub.

Header fields (between the --- lines): title, type, aliases, image, summary, cards, comic, series, infobox.
  type: character, ranger, team, villain, monster, zord, show, comic-series, comic-issue, place, item or topic
  image: card:<character name>, cover:<comic id>, deck:<deck id>, or an https:// link
  infobox: Key = Value | Key = Value   (values can hold [[links]])
Links: [[Title]] or [[Title|text shown]]. A link to a page that doesn't exist yet shows in red.

House style: plain, specific prose in the past or present tense used by the rest of the page. No emojis, no hype,
no filler words such as "real", "genuine" or "actual" where they add nothing. Write summaries in your own words;
don't copy dialogue or captions beyond a short quote.
